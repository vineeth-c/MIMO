# MIMO - My Interactive Mini Organizer

MIMO is an expressive, interactive desktop companion.

## Development Environment

- Ubuntu (WSL2)
- C++17
- CMake
- Ninja
- GDB
- Git

## current Features

- basic firmware simulator
- CMake-based build system
- Automated startup smoke test

## Build Instructions
cmake -S . -B build -G Ninja
cmake --build build

## Run
./build/mimo
